# Matrix Messenger

Мессенджер в стиле "Матрицы" на Python + Tkinter.
Чёрный фон, неоново-зелёный текст, регистрация по email, добавление друзей, общий и личные чаты.

## Возможности

- Регистрация и вход по email + пароль (хранится в SQLite, хешируется через PBKDF2)
- Добавление друзей по email
- Общий чат для всех онлайн-пользователей
- Личные сообщения между друзьями (двойной клик по другу в списке)
- Система заявок в друзья: отправить, принять, отклонить
- Матричная тема: чёрный фон, зелёный неон, анимация падающих символов
- Всё в одном файле: и сервер, и клиент

## Как запустить

### Вариант 1. Готовый .exe (Windows)

1. Скачай MatrixMessenger.exe
2. Правый клик, Свойства, внизу галочка "Разблокировать", OK
3. Двойной клик по файлу
4. Если появится синее окно SmartScreen, нажми "Подробнее", затем "Выполнить в любом случае"
5. Windows Firewall спросит про доступ к сети, разреши

### Вариант 2. Из исходного кода

Требуется Python 3.10 или новее.

    pip install pyinstaller
    python matrix_messenger.py

## Как начать общение

### Если ты хост (держит сервер)

1. Запусти программу
2. Нажми "СЕРВЕР", увидишь надпись "сервер слушает порт 5555"
3. Узнай свой IP командой ipconfig (например 192.168.1.42)
4. Скажи другу: "Мой IP 192.168.1.42, порт 5555"

### Если ты гость

1. Запусти программу
2. В поле IP введи IP хоста (например 192.168.1.42)
3. Поле Порт оставь 5555
4. Вкладка РЕГИСТРАЦИЯ, введи email, пароль, ник, нажми "Зарегистрироваться"

### Добавление в друзья

1. В боковой панели введи email друга, нажми Enter или +
2. Друг увидит заявку в блоке "ЗАЯВКИ", нажмёт "Принять"
3. Теперь вы друзья, двойной клик по нику откроет личный чат

## Управление

| Кнопка | Что делает |
|---|---|
| СЕРВЕР | Запускает сервер локально |
| СЕРВЕР + ВОЙТИ | Запускает сервер и сразу подключает тебя |
| ВОЙТИ | Подключение к серверу как гость |
| ОБЩИЙ ЧАТ | Вернуться из личного чата в общий |
| Двойной клик по другу | Открыть личный чат |
| Enter в поле ввода | Отправить сообщение |

## Если вы в разных сетях (через интернет)

Используйте Radmin VPN, Hamachi или ZeroTier:

1. Оба ставите клиент VPN, подключаетесь к одной виртуальной сети
2. Хост смотрит свой виртуальный IP (например 26.12.34.56)
3. Гость вводит его в поле IP мессенджера

## Технологии

- Python 3, язык
- Tkinter, GUI
- Socket, сеть (TCP, JSON-протокол с разделителем перевод строки)
- Threading, многопоточность (сервер и клиент)
- SQLite, база данных пользователей и друзей
- hashlib (PBKDF2-SHA256), хеширование паролей
